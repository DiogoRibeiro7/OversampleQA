# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to dfr@esmad.ipp.pt.

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work with you to resolve the issue.

## Security Considerations

When using OversampleQA:
- Be cautious with sensitive datasets
- Validate results before using in production
- Keep dependencies updated
- Use appropriate data anonymization when needed
