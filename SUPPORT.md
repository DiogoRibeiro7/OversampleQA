## Quick Help

### Installation Issues
```bash
# Ensure you have Python 3.10+
python --version

# Install from source (OversampleQA is not published on PyPI)
git clone https://github.com/diogoribeiro7/OversampleQA.git
cd OversampleQA
pip install -e .
```

### Common Problems

**Import Error**: Make sure oversampleqa is installed: `pip list | findstr oversampleqa`

**Slow Performance**: Try using `metric="euclidean"` instead of `"hassanat"`

**Memory Issues**: Reduce dataset size or use `hidden_ratio=0.05` for testing
